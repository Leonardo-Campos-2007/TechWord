# SPRINTS

## Regra Geral

A equipe não deve avançar para a próxima Sprint enquanto as funcionalidades obrigatórias da Sprint atual não estiverem funcionando e testadas no Postman.

---

## Sprint 1 — Base de Usuários

Antes de avançar:

```text
[ ] Cadastro de usuário
[ ] Login
[ ] Consulta de usuário
[ ] Edição de perfil
[ ] Validação dos endpoints no Postman
```
